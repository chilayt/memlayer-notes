# Agent 记忆层评测方法学（规范）

> 一套可复现、防自欺的记忆层评测方法。核心立场：**先冻结、再测、配对比较、盲校准**，不用「看起来不错」下结论。
>
> **权威版本**：英文 `SPEC.md`。中文为译文，若有出入以英文为准。
> **参考实现范围**：`reference/` 是**教学演示**（槽位聚合 + 精确 McNemar），**未**实现完整评测框架（无非劣效界值/CI、无冻结集哈希、无数值部分分规则）。那些是下面的要求，不是已交付代码。

## 0. 为什么需要这套方法

记忆层评测极易自欺：题是随手出的、判分是松的、对比是不同语料的、提升是噪声。本方法用四道闸挡住这些：
1. **冻结**：题集/判分规则/提示词先固定并哈希，测后不改。
2. **同语料配对**：两个系统用**同一套事实**，逐题配对，而非各测各的。
3. **槽位判分**：把「答对」拆成必要事实槽位，逐槽判，不用整体印象。
4. **盲校准**：多个独立评审盲审，检验判分本身有没有偏。

## 1. 冻结题集

- 每题标注类型：`recall`(召回) / `state`(当前状态) / `rule`(规则) / `conflict`(冲突) / `refuse`(应答不知道) / `cross`(跨项目，应隔离)。
- 每题绑定**必要事实槽位**（见 §2）与标准答案要点。
- 题集 + 槽位 + 判分提示词一起 SHA-256 冻结，记录版本。**测后改题 = 作废重测。**
- 必须含 `refuse` 与 `cross` 题：只测「答对」会奖励编造。

## 2. 槽位判分（slot grading）

把每题拆成 2–4 个**必要事实槽位**。每槽独立判：
- `pass`：回答明确覆盖该槽位，且与证据一致。
- `fail`：回答与该槽位矛盾，或编造。
- `insufficient`：回答未覆盖该槽位（没提）。

**必要性检验（delete-it-would-mislead）**：一个槽位是「必要」的，当且仅当**删掉它会让回答误导**。这挡住把无关细节算成得分点。

题级判定：所有必要槽位 `pass` → 题对；任一 `fail` → 题错；否则记部分分。**必须预定义数值聚合规则**（如必要槽位通过比例），并对两系统同样适用。参考实现的粗粒度 `"partial"` 标签只是占位，不是该规则。

**判分必须引用证据**：每个槽位判定附原文引用，禁止凭印象。

## 3. 同语料配对 + McNemar

- 两系统注入**同一套事实**，同一题集，逐题配对。
- **配对单元是「题」，不是「次」。** 若每题跑多次，先用**预定义规则**（如多数票）把重复折叠成每题一个结果再配对。原始重复不独立，不能当独立配对喂入。
- 记录每题两系统对错 → 2×2 表；McNemar 只看不一致对 (b, c)。
- **小样本用精确（二项）McNemar。** 连续性校正卡方在 b+c 较小（< ~20）时不可靠；报告精确双侧 p。
- **「不显著」≠「等价」，且非劣效 ≠ 等价。** 非劣效需预定义界值 + 单侧 CI 界；等价需**双侧**界都落在预定义界值内。明确你声明的是哪一个。

## 4. 盲校准（判分的判分）

判分器本身可能有偏。用多个**独立模型家族**盲审同一批回答：
- 回答匿名化为「甲/乙」，评审不知道哪个是哪个系统。
- 分层抽样：**分歧题富集**（两判分器不一致的）+ 双错题 + 少量对照。
- 计算评审间一致率（槽位级 + 题级）；分歧由第三方裁决。
- 一致率高 → 判分可信；低 → 先修判分规则再谈系统优劣。

## 5. 报告要求

- 报告**分母与原始次数**，不只报百分比。
- 分桶：漏召回 / 召回了但答错 / 合理拒答 / 编造 / 安全失败。
- 声明样本量与不确定性；小样本筛查不得当结论。
- 记录成本（token/延迟），因为「更准但贵 10 倍」是不同结论。

## 6. 常见自欺清单（对照自查）

- [ ] 题是测后改的？→ 作废
- [ ] 两系统用不同语料？→ 不是公平对比
- [ ] 只测答对、不测拒答/隔离？→ 奖励编造
- [ ] 判分无证据引用？→ 印象分
- [ ] 「不显著」当「等价」？→ 非劣效需界值+单侧界；等价需双侧界
- [ ] 只报百分比不报分母？→ 不可复核

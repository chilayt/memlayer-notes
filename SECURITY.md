# Security Policy

## Scope

This repository is a methodology notebook with small reference demos. It is
**not a deployed service** and ships no running memory system. The retraction
mechanisms discussed in docs/SAFETY-BOUNDARIES.md are design goals, not
implemented here.

## Reporting a vulnerability

If you find a security issue in the reference code or a data-leak in the
published content, please report it privately to the maintainers (contact to
be set before publishing) rather than opening a public issue.

## A standing reminder

Retraction is not forgetting. See docs/SAFETY-BOUNDARIES.md for residual-risk
boundaries (backups, git history, logs, embeddings, provider retention).

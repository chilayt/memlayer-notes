# Contributing

Thanks for your interest. This is a research notebook; contributions that improve
correctness, clarity, or reproducibility are welcome.

## Ground rules

- **No real user/project data.** All examples must be synthetic. Do not paste
  logs, facts, credentials, or identifiable project details.
- Keep claims honest: distinguish mechanism (reproducible) from anecdotal
  adoption numbers; do not present small-sample flips as significant results.
- If you change the eval spec, keep SPEC.md (authoritative) and SPEC.zh.md in sync.
- Reference code must run on the Python standard library alone.

See SECURITY.md for sensitive reports; use normal issues for everything else.
